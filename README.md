## 📱 Programação para Dispositivos Móveis

Repositório centralizador de conteúdos, anotações teóricas, listas de exercícios, laboratórios práticos e projetos desenvolvidos ao longo da disciplina de **Programação para Dispositivos Móveis**.

---

### 🎯 Objetivos

- Compreender conceitos fundamentais do ecossistema de desenvolvimento mobile (ciclo de vida, layout responsivo, persistência local e consumo de APIs).
- Implementar interfaces modernas, acessíveis e reativas.
- Praticar boas práticas de arquitetura de software, componentização e gerenciamento de estado.
- Desenvolver projetos práticos integrando serviços externos e armazenamento de dados.
